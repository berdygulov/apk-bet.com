# apk-bet.com — первоочередные правки по итогам SEO-аудита

**Дата:** 21.10.2026
**Основание:** предварительный аудит от 20.10.2026 (проверены все 195 страниц из sitemap)
**Кому:** разработчику / контент-менеджеру сайта

> У каждой правки есть код (F-01 и т. д.). В ответе по выполнению указывайте код и статус. Пункт считается выполненным, когда выполнен его критерий приёмки.

## Приоритет 1 — критично, исправить в первую очередь

### F-01. Кнопки «Sayt» в рейтинге никуда не ведут
- **Где:** главная `/uz/`, `/ru/`, рейтинги в разделах (bookmakers, bonuses, apps, casinos).
- **Сейчас:** все кнопки «Sayt» / «Сайт» ссылаются на `/uz/` (заглушка).
- **Нужно:** поставить рабочие ссылки на сайты БК (партнёрские). Внешним ссылкам добавить `rel="sponsored nofollow"` и `target="_blank"`. Если используются редиректы вида `/go/brand/`, закрыть их в robots.txt (`Disallow: /go/`).
- **Требуется от владельца:** список партнёрских ссылок по каждому БК.
- **Критерий приёмки:** каждая кнопка «Sayt» открывает сайт своего БК.

### F-02. Не указаны бонусы в рейтинге
- **Где:** рейтинговые таблицы на главной и в разделах.
- **Сейчас:** у всех БК одинаковый текст «Birinchi depozit bonusi», без суммы и условий.
- **Нужно:** указать конкретный бонус каждого БК (например, «100% до 1 500 000 UZS»), на обеих языковых версиях.
- **Критерий приёмки:** у каждого БК в таблице свой бонус с суммой.

### F-03. Счётчики аналитики и подтверждение прав на сайт
- **Сейчас:** в коде не найдены Google Analytics / Google Tag Manager, Яндекс.Метрика и мета-тег подтверждения Google Search Console.
- **Нужно:** установить GTM (в него — GA4) и Яндекс.Метрику на все страницы; подтвердить сайт в Google Search Console и Яндекс.Вебмастере (через DNS или мета-тег). Доступы выдать SEO-специалисту.
- **Критерий приёмки:** данные приходят в GA4 и Метрику, сайт подтверждён в GSC, sitemap отправлен.

### F-04. Два H1 на странице
- **Где:** 168 из 195 страниц, в основном шаблон обзоров БК и их подстраниц (`/bookmakers/<brand>/`, `/apps/`, `/bonuses/`, `/login/`, `/casino/`, `/partner/`).
- **Сейчас:** первый H1 — название бренда в нижнем регистре (`<h1>mostbet</h1>`), второй — основной заголовок (`<h1>Mostbet platformasiga umumiy sharh</h1>`).
- **Нужно:** оставить один H1 — основной заголовок. Название бренда вывести через `div` / `span` / `p` (оформление можно сохранить через CSS).
- **Критерий приёмки:** на каждой странице сайта ровно один `<h1>`.

### F-05. Пустые страницы в индексе
- **Где:** `/uz/previews/`, `/ru/previews/`.
- **Сейчас:** страницы отдают код 200, но на них нет текста, title, H1 и description. Обе есть в sitemap.
- **Нужно (вариант на выбор):**
  - **а)** до наполнения поставить `noindex, follow` и убрать из sitemap (в Yoast: «Разрешить показ в результатах поиска — Нет»);
  - **б)** вывести на хабе список дочерних страниц (football, basketball, cricket, hockey, tennis), добавить title, H1, description и вводный текст (текст предоставит SEO-специалист).
- **Критерий приёмки:** нет индексируемых страниц без title и контента.

## Приоритет 2 — важно, исправить следом

### F-06. Шаблонные title и пустые description
- **Сейчас:** 12 страниц с автоматическими английскими title. Не менее 14 страниц без meta description: эти 12 плюс хабы `/previews/`.

| URL | Текущий title |
|-----|---------------|
| `/uz/previews/football/` | Football UZ - apk-bet.com |
| `/uz/previews/basketball/` | Basketball UZ - apk-bet.com |
| `/uz/previews/cricket/` | Cricket UZ - apk-bet.com |
| `/uz/previews/hockey/` | Hockey UZ - apk-bet.com |
| `/uz/previews/tennis/` | Tennis UZ - apk-bet.com |
| `/ru/previews/football/` | Football RU - apk-bet.com |
| `/ru/previews/basketball/` | Basketball - apk-bet.com |
| `/ru/previews/cricket/` | Cricket RU - apk-bet.com |
| `/ru/previews/hockey/` | Hockey RU - apk-bet.com |
| `/ru/previews/tennis/` | Tennis RU - apk-bet.com |
| `/uz/bookmakers/` | Bookmakers UZ - apk-bet.com |
| `/ru/bookmakers/` | Bookmakers RU - apk-bet.com |

- **Нужно:** прописать уникальные title и description в Yoast на языке страницы (тексты предоставит SEO-специалист). На страницах previews также добавить H1 — сейчас его нет.
- **Критерий приёмки:** у всех страниц из sitemap уникальный title на языке страницы и заполненный description.

### F-07. Битые ссылки и лишние редиректы в навигации
- `/uz/uz/` — ссылка в шапке (переключатель языка / флаг). Отдаёт редирект на `/uz/`. Исправить на `/uz/`.
- `/uz/previews/football` (без слэша) в меню. Отдаёт редирект на версию со слэшем. Исправить на `/uz/previews/football/`.
- Проверить аналогичные ссылки в версии `/ru/`.
- **Критерий приёмки:** внутренние ссылки в меню и шапке отдают код 200 без редиректа.

### F-08. Sitemap и hreflang
- Убрать из `page-sitemap.xml` адрес `https://apk-bet.com/`: он перенаправляет на `/uz/`, а в sitemap должны быть только страницы с кодом 200.
- Добавить `<link rel="alternate" hreflang="x-default" href="https://apk-bet.com/uz/">` (или на ту версию, которая открывается по умолчанию) на все страницы — в паре с существующими `ru` / `uz`.
- **Критерий приёмки:** в sitemap нет адресов с редиректом, на страницах есть `x-default`.

### F-09. Обязательные элементы для гемблинг-сайта
- В футер на всех страницах добавить: значок **18+**, короткий текст об ответственной игре, ссылки на служебные страницы.
- Создать страницы (uz + ru): «О нас», «Контакты», «Политика конфиденциальности», «Ответственная игра». Тексты предоставит SEO-специалист или владелец; разработчику подготовить шаблоны и ссылки в футере.
- **Критерий приёмки:** в футере есть 18+ и рабочие ссылки на 4 служебные страницы.

### F-10. Рейтинг на главной: alt, текст, опечатка
- 22 изображения на главной без атрибута `alt` — прописать (для логотипов: «Mostbet logo» и т. п.).
- Названия БК в таблице рейтинга выводятся только логотипом — добавить название текстом (можно визуально скромно).
- Опечатка в заголовке блока: «Bukmey**k**erlar reytingi» → «Bukmekerlar reytingi».
- **Критерий приёмки:** у всех изображений на главной есть alt, название каждого БК есть в HTML текстом, опечатка исправлена.
