# Отчёты по SEO-плану apk-bet.com

Отчёты по пунктам из [SEO-plan.md](../SEO-plan.md). Одна папка на неделю: `ГГГГ-ММ-неделя-N/` (N — номер недели месяца, неделя с понедельника по пятницу). В папке — отчёт `ГГГГ-ММ-неделя-N.md` и всё, что сделано за эту неделю: выгрузки (`data/`), скриншоты (`screens/`), отдельные списки. Общие файлы проекта — в корне репозитория: план, приоритетные исправления, sitemap.

## Структура недельного отчёта

0. **Коды, упомянутые в отчёте** — расшифровка кодов из журнала, чтобы отчёт читался без SEO-plan.md.
1. **Журнал** — строки в формате плана (раздел 7): `Дата | Код пункта | Что сделано | URL / объём | Результат / статус`.
2. **Подробности по пунктам** — что сделано, как проверено, найденные проблемы.
3. **Ожидает** — что ждёт других людей (контент-менеджер, разработчик) или поисковых систем.
